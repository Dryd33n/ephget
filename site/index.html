ephget

Desktop shortcuts for portable Windows apps that download on first use and clean up after themselves.

irm https://github.com/Dryd33n/ephget/releases/latest/download/install.ps1 | iex

Run it in PowerShell. It needs no admin rights. Windows Defender or SmartScreen may warn about ephget, because it isn't code-signed yet and it downloads and starts other programs.
